Accessibility Conformance Report

Based on VPAT® Version 2.5Rev (EU edition: WCAG and EN 301 549)

Report information
Name of product and versionITSG-33 Compliance Navigator 1.1.0
Report date2026-10-15 (manual evaluation); automated results recompiled with each commit
Product descriptionA browser-based tool for reviewing a software product against Canada's ITSG-33 security controls: scoping interview, documentation review, a guided questionnaire with “Gemba walk” guidance for each control, and a generated compliance report. Runs entirely in the browser with no server-side processing or authentication.
Contact informationReport an accessibility problem (project issue tracker, github.com/numbap/Itsg33)
EvaluatorClaude (AI assistant, Anthropic). Self-assessment; no accessibility certification; not independent
Evaluation methods usedWCAG 2.2 A/AA evaluation combining (1) axe-core automated rules on every page state in light and dark themes; (2) scripted Playwright checks for keyboard access, keyboard traps, focus visibility and contrast, focus obscuring, reflow at 320 CSS px, resize at 200%, text spacing, target size, non-text contrast, ARIA tabs, focus management and status messages; (3) code review of templates, styles and event handling; (4) visual inspection of light, dark and forced-colours rendering at several widths; and (5) review of the generated accessibility tree. Details are in the test methodology and test report.

Build status

Automated suite passed: 51 axe-core runs with no WCAG violations, and 275 scripted checks passed across 17 page states (axe-core 4.14.0, Chromium (Playwright 1.56.1)).

Manual review is current: the code-review and visual judgements were made on the same user-interface code this report describes (fingerprint 0cbabeba9d721dbc).

Notes

  • Scope: the complete web interface (all views and states listed in the scope document) and the accessibility documentation pages. Generated export files (Markdown, CSV, JSON, printed PDF) are not evaluated as non-web documents.
  • Evaluator: this report is a self-assessment carried out by an AI assistant (Claude, Anthropic) using automated tools, scripted browser checks, code review and visual inspection. No testing with screen readers or other assistive technology, and no testing by people with disabilities, has been performed yet. Only Chromium was tested. Independent verification is recommended; see the expertise and independence statement.
  • Conformance levels for criteria with automated checks are recompiled on every commit. If an automated check fails, the affected criterion is downgraded automatically.
